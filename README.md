# Shelltify

## Installation

Follow these steps to install and run Shelltify.

### 1. Extract the files

Download the latest release and **extract the entire ZIP file** to a folder of your choice.

> Make sure you extract the files before running the program. Do not run it directly from inside the ZIP archive.

### 2. Run Shelltify

Open the extracted folder and locate the `.bat` file.

Double-click the `.bat` file to launch Shelltify.

```text
Shelltify/
├── dist/          # Executable may be located here
├── bin/           # Or the executable may be located here
├── launcher.bat   # Run this file
└── ...
```

### 3. Run the executable directly

If you prefer to launch Shelltify directly, the `.exe` file can be found in either:

- `dist/`
- `bin/`

Open the appropriate folder and run the `.exe`.

## Troubleshooting

### Windows blocks the application

If Windows displays a security warning, verify that you downloaded Shelltify from the official repository or release page.

### The `.bat` file doesn't work

Make sure you **extracted the complete archive** and kept the original folder structure. The `.bat` launcher may depend on files located in `dist/` or `bin/`.

### Missing files

Re-download the latest release and extract it again. Do not move individual files out of their original folders.

## Quick Start

**Download → Extract → Run the `.bat` file**

The standalone `.exe` is also available inside the `dist/` or `bin/` folder.****
